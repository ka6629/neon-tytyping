ネオンタイピング自動タイパー

このページを GitHub Pages などにデプロイすると、別の PC から URL を送って使えるようになります。

使い方

  1. まず 別タブで `https://otonasi-muonn.github.io/typing_game/` を開きます。
  2. このページの下にある「ブックマークレットコードをコピー」を押します。
  3. コピーしたコードをブラウザのブックマークの URL 部分に貼り付けて、ブックマークを作成します。
  4. タイピングゲームページでそのブックマークをクリックすると、自動入力が開始します。

ブックマークレット

ブックマークに登録するか、コピーして手動で URL に貼り付けてください。

Console での使い方

ブックマークレットが使えない場合は、`autotyper-console.js` を開いて、内容をコピーし、タイピングページの開発者ツール Console に貼り付けて実行してください。

  • autotyper-console.js を開く

補足

  • このページ自体はホスト先の URL から開くだけで動きます。
  • GitHub Pages で公開すれば、他の PC に URL を送れます。
  • `controller.html` は別 origin からでは動作しないため、ブックマークレット方式を推奨します。
このページを公開して URL を送れば、他の PC からも同じ手順で自動タイピングを使えます。
