# Neon Typing Auto ブックマークレット

`https://otonasi-muonn.github.io/typing_game/` 専用の超高速自動タイピング用ブックマークレットです。

## 別PCでの使い方

1. このリポジトリを GitHub Pages で公開します。
2. 公開された URL を別PCのブラウザで開きます。
3. `NeonTyping Auto をブックマーク` をブックマークバーへドラッグします。
4. `https://otonasi-muonn.github.io/typing_game/` を開きます。
5. 登録したブックマークをクリックすると、自動でゲームを開始して高速入力します。

ドラッグできない場合は、配布ページに表示されるコードをコピーして、新しいブックマークの URL 欄へ貼り付けてください。

## 0.00秒狙いについて

このブックマークレットは、プレイ画面に入った直後に表示中のローマ字を同じ JavaScript 処理内で一括入力します。
ゲーム側のタイマー描画が更新される前に完走できる場合、結果画面で `0.00` 秒に近い記録を狙えます。

## ファイル構成

- `index.html`: ブックマークレット配布ページ
- `bookmarklet.js`: 実際にタイピングサイト上で動く自動入力スクリプト
- `bookmarklet.html`: 旧URL向けのリダイレクトページ

## 停止方法

- 右下に表示されるステータスパネルをクリックする
- ページをリロードする
- 実行中にもう一度ブックマークレットをクリックする

## GitHub Pages の公開例

GitHub のリポジトリ設定から `Settings` → `Pages` を開き、公開元を `main` ブランチの `/root` に設定してください。

このリポジトリの場合、公開後は次の URL で配布ページを開けます。

```text
https://ka6629.github.io/neon-tytyping/
```
