# ネオンタイピング自動タイパー

このリポジトリには、`https://otonasi-muonn.github.io/typing_game/` 向けの Chrome 拡張機能が含まれています。

## 使い方

1. Chrome で `chrome://extensions/` を開きます。
2. 右上の「デベロッパーモード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、このフォルダを選択します。
4. `https://otonasi-muonn.github.io/typing_game/` を開きます。
5. 拡張機能アイコンをクリックし、「開始」を押します。

## 機能

- 画面上のローマ字表示から次に入力する文字を取得して自動入力します。
- `IDLE` 画面であれば自動的にゲームを開始します。
- 速度スライダーでキー送信間隔を調整できます。
- 停止ボタンで自動入力を止められます。
